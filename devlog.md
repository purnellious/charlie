Round 1: an attribute-aware regex (itself already a fix for a simpler edge case) still matched the *first text occurrence* of anything `<body...>`-shaped anywhere in a string, including one an attacker plants inside an HTML comment or `<script>` string (`<!--<body>-->`) earlier than the real tag — splicing the entire "Forwarded message" disclosure block (sender identity, subject, date, Jonathan's note) into the comment, invisible to any renderer, while the attacker's real content displayed with zero indication it was forwarded from someone else. Fixed by not reconstructing from line/column at all — overriding `parse_starttag()` to capture its own real absolute-offset return value directly.
